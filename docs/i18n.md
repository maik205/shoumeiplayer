# Internationalization

Shoumei Player uses Android string resources as the source of truth for app-owned
copy. The default `values/` resources are English. A translation adds the same
keys under a qualified directory such as `values-de/strings.xml`, then adds that
locale tag to `res/xml/locales_config.xml`.

## Compose

Resolve static copy with `stringResource(R.string.some_key)`. Use Android format
arguments and plurals instead of joining translated fragments.

ViewModels and repositories must not resolve resources into English strings.
When text has to cross into Compose, use `UiText.Resource`. Use `UiText.Dynamic`
only for content owned by a Jellyfin server or another external source, then call
`resolve()` at the Compose boundary.

## Naming

Use a feature prefix (`tv_`, `settings_`, `player_`) and name the meaning rather
than the current English wording. Mark protocol tokens, URLs, and other
non-translatable values with `translatable="false"`.

## Adding a locale

1. Copy the keys to `app/src/main/res/values-<tag>/`.
2. Translate complete messages; do not concatenate translated fragments.
3. Add the BCP 47 tag to `app/src/main/res/xml/locales_config.xml`.
4. Check long copy, focus behavior, truncation, and right-to-left layout on a TV
   target. Android exposes the declared languages in per-app language settings
   on supported devices.
